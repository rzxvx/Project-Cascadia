# P105AP (iPad mini 1) framebuffer — confirmed Aug 2026 via fb-probe

## Layout

| Symbol | Value | Notes |
|--------|-------|-------|
| `FB_PHYS` / marker | `0x9f6fbf00` | 64 px pre-scanout tag in RAM — **not visible** |
| Scanout base | `0x9f6fc000` | `FB_PHYS + 64×4` — first pixel CLCD reads |
| Width | **768** px | 769th pixel in a row wraps to next row |
| Height | **1024** rows | Portrait panel geometry |
| Stride | **3072** B | `768 × 4` (32 bpp X8R8G8B8) |

## Probes

- **memprobe** — fills scanout planes green/magenta (`FB0` @ `0x9f6fc000`, width 768)
- **fb-probe** — red marker in pre-FB RAM @ `0x9f6fbf00`; green line on row 0 of scanout (768 px)
- **fb-text** — dark background, RGBW bars, white ASCII text (8×8 font, scale 2); **uses direct.dfu only**
- **gpio-poll** — GPIO dump @ `0x3FA00000` + live Home/vol/hold pin poll; see [p105-gpio.md](p105-gpio.md)

Tune green line row/offset:

```bash
python3 scripts/fb-probe-config.py --row 100 --pixel-off 0 --pixel-count 768 --rebuild --deploy
```

Tune fb-text messages/colors:

```bash
python3 scripts/fb-text-config.py --show
python3 scripts/fb-text-config.py --line "Hello P105" --line "768x1024 OK" --rebuild --deploy
bash flashdrive/boot-fb-text.sh        # on laptop
```

## Kernel early debug

Linux uses the same geometry (`0x9f6fc000` / 768×1024 / stride 3072) and
`p105_fb_dbg()` text milestones (no color bands). Rebuild:

```bash
make dtb
bash scripts/build-kernel.sh
bash scripts/build-staging-bundle.sh
bash scripts/deploy-linux-ace.sh
```


| Payload | iBEC | Upload |
|---------|------|--------|
| memprobe / fb-probe / **fb-text** / **gpio-poll** | `direct.dfu` (ep4 magic) | ≤64 KiB |
| fb-image (PNG) | `autogo.dfu` (EOF jump) | ~3 MiB pack — **broken on your setup** |

```bash
bash scripts/build-fb-image.sh          # assets/test-768x1024.png → pack
bash flashdrive/boot-fb-image.sh        # on laptop
```

Replace `assets/test-768x1024.png` (must be exactly 768×1024), rebuild, redeploy.
