# Actual selected kDFU loader and IOP sleep boundary

Read-only primary inspection of Legacy-iOS-Kit revision `c9dfd212e6f59188c74026b20bf96f2f06e339f9` confirms normal-mode iOS9 selects `resources/kloader/kloader` (Odysseus), SHA256 `bec212b4d99a1e3b9fa4add663fa884a2435045d1e47051415f4e26e197f8132`. The axi0mX variant is the older-iOS branch; its source cannot establish this selected binary's behavior. Cascadia calls `restore.sh --kdfu`; none of these tools was executed on a device.

Actual Mach-O import binding identifies late calls `b0e2 -> IOPMFindPowerManagement` and `b0f0 -> IOPMSleepSystem`. Eight bounded original-prefix cases pass: absent port or sleep API error reaches the native error import; accepted sleep loops through sleep3 and retries if execution remains. Imports are fake. Earlier exploit/kernel/payload writes are excluded from the instruction scope. A successful system request is not a completed handoff.

Official13G36 kernelcache SHA256 `8eae16f060a71d4f3790385951588f8198d0f21cdb74146f9750941a3d764125` independently binds EmbeddedIOP sleep to actual AppleA5IOP stopCPU `811b4a35`. Thirty-two original interprocedural sleep cases and32 quiesce prefixes pass. Native stop requests IRQ-disable, core-control0, power-off and clock-off, clears a software running flag and returns success despite all8 fake callback-error combinations. A matching quiesce prefix checks the software byte, without physical IOP/DMA status. Already-inactive EmbeddedIOP with a running provider skips stop and reaches a native assertion instead. No12H offset is silently reused.

The separate embedded CPU sleep-body audit runs32 controls across12H321 and13G36, checking20 exact instructions. Context/cache helpers are explicit unexecuted fakes. The ARM leaf has DSB, a private marker store and WFI; WFI is intercepted as synthetic wake/observer. Selector0 repeats the wait when it returns; simulated context restoration checks software counters. CPU-model DSB and sleeping software do not fence another bus master's DMA. Adjacent PMGR wake-handshake leads remain static, with physical semantics unqualified.

Root independently reproduced all three frozen groups and exact JSON equality. No loader, exploit, real sleep, device MMIO, NAND access or boot was performed. The full power tree, native control-message completion, inherited DMA state, halt acknowledgment and IRQ lifetime remain distinct obligations. This evidence supports retaining WAIT_FENCE; it supplies no permission for speculative reset or NAND writes.
